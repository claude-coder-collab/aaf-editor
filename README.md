# aaf-editor

A from-scratch C++ library and cross-platform desktop editor for AAF (Advanced Authoring Format) files, with a webview UI.

See [SPEC.md](SPEC.md) for the full specification.

## Reference material

- AAF sample files from the AAF SDK 1.2.0 are in `tests/fixtures/aafsdk/` (AAF SDK Public Source License, see `LEGAL/`).
- The AAF specification PDFs are not redistributable. Fetch them locally with `python3 tools/fetch_specs.py` (writes to `docs/reference/`).
